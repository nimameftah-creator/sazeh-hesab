# دفتر ساختمان — راهنمای نصب

داشبورد مدیریت مالی پروژه‌های ساختمانی: هزینه‌ها، مراحل ساخت، پیمانکاران،
چک‌ها، قیمت مصالح و گزارش‌ساز.

---

## 📋 قبل از شروع: کدام روش را می‌خواهی؟

| روش | برای چه کسی | سختی |
|---|---|---|
| **الف)** فقط استفاده در مرورگر | می‌خواهم سریع شروع کنم | ⭐ آسان |
| **ب)** نصب روی کامپیوتر (فایل `.exe`) | می‌خواهم آیکون و پنجره مستقل داشته باشم | ⭐⭐ متوسط |
| **ج)** اجرای کامل روی کامپیوتر خودم | می‌خواهم داده‌ها روی سیستم خودم باشد | ⭐⭐⭐ کامل |

> ⚠️ **مهم:** این برنامه برای کار به **دیتابیس PostgreSQL** نیاز دارد.
> روش‌های «الف» و «ب» از سروری که برنامه روی آن مستقر است استفاده می‌کنند.
> روش «ج» همه‌چیز را روی کامپیوتر خودت اجرا می‌کند.

# روش الف — استفاده در مرورگر (ساده‌ترین)

۱. آدرس برنامه را در مرورگر باز کن.

۲. نصبش کن (اختیاری ولی پیشنهادی):

| دستگاه | مراحل |
|---|---|
| **ویندوز** | Edge یا Chrome ← آیکون نصب در نوار آدرس (سمت چپ) ← تایید |
| **مک** | Chrome ← منوی `⋮` ← `Cast, save, and share` ← `Install page as app` |
| **آیفون** | Safari ← دکمه اشتراک ← `Add to Home Screen` |
| **اندروید** | Chrome ← منوی `⋮` ← `Install app` |

تمام. آیکون روی صفحه اصلی / منوی Start می‌آید.

# روش ب — فایل نصبی `.exe` / `.dmg`

## پیش‌نیاز
**Node.js نسخه ۲۰ یا بالاتر** → دانلود از https://nodejs.org (نسخه **LTS**)

برای بررسی نصب بودنش، در CMD یا PowerShell بنویس:
```bash
node -v
```
باید چیزی مثل `v22.11.0` نشان دهد.

## سه دستور

```bash
cd desktop
npm install
npm run dist:win
```

> روی مک به‌جای آخرین دستور: `npm run dist:mac`

فایل نصبی در **`desktop/release/`** ساخته می‌شود:

| فایل | توضیح |
|---|---|
| `daftar-sakhteman-1.0.0-x64.exe` | 🪟 **این را نصب کن** |
| `daftar-sakhteman-1.0.0-portable.exe` | بدون نصب — فقط دابل‌کلیک |
| `daftar-sakhteman-1.0.0-x64.dmg` | 🍎 مک اینتل |
| `daftar-sakhteman-1.0.0-arm64.dmg` | 🍎 مک M1/M2/M3 |

## نصب فایل `.exe` روی ویندوز

۱. روی فایل `daftar-sakhteman-1.0.0-x64.exe` **دابل‌کلیک** کن
۲. اگر ویندوز هشدار آبی داد (SmartScreen):
   - روی **More info** کلیک کن
   - بعد **Run anyway**
   > این هشدار به این دلیل است که برنامه «امضای دیجیتال» ندارد. طبیعی است.
۳. مسیر نصب را انتخاب کن (پیش‌فرض خوب است) ← **Install**
۴. تمام — آیکون در منوی Start و روی دسکتاپ

## ⚠️ بعد از نصب: آدرس سرور را تنظیم کن

نسخه دسکتاپ به‌صورت پیش‌فرض به `http://localhost:3000` وصل می‌شود.
اگر برنامه جای دیگری است:

۱. برنامه را باز کن
۲. منوی **برنامه** ← **تغییر آدرس سرور...**
۳. آدرس را بنویس و **ذخیره** کن

> ✅ نیازی به ساخت دوباره فایل نصبی نیست — آدرس ذخیره می‌شود.

# روش ج — اجرای کامل روی کامپیوتر خودت

این روش همه‌چیز را (برنامه + دیتابیس) روی کامپیوتر خودت اجرا می‌کند.

## قدم ۱: پیش‌نیازها را نصب کن

| ابزار | از کجا |
|---|---|
| **Node.js ۲۰+** | https://nodejs.org (نسخه LTS) |
| **Docker Desktop** | https://docker.com/products/docker-desktop |

هر دو را نصب کن و یک بار سیستم را ری‌استارت کن.

## قدم ۲: دیتابیس را بالا بیاور

در پوشه اصلی پروژه:

```bash
docker compose up -d
```

یک بار اجرا می‌شود و PostgreSQL در پس‌زمینه می‌ماند.
برای بررسی:
```bash
docker compose ps
```
باید `healthy` نشان دهد.

> **دیتابیس ابری نمی‌خواهی؟** می‌توانی PostgreSQL را مستقیم نصب کنی:
> https://postgresql.org/download — موقع نصب رمز را `postgres` بگذار.

## قدم ۳: فایل تنظیمات را بساز

**ویندوز (CMD):**
```bash
copy .env.example .env
```

**مک / لینوکس:**
```bash
cp .env.example .env
```

اگر دیتابیس را با Docker بالا آوردی، **نیازی به ویرایش نیست**.
اگر رمز دیگری دادی، فایل `.env` را باز کن و `DATABASE_URL` را اصلاح کن.

## قدم ۴: وابستگی‌ها را نصب کن

```bash
npm install
```

## قدم ۵: جدول‌های دیتابیس را بساز

```bash
npx drizzle-kit push
```

## قدم ۶: داده‌های پایه را وارد کن

این دستور **دسته‌بندی‌ها** (سیمان، میلگرد، آرماتور، نازک‌کاری...) و
**کاتالوگ کالاها** (۶۱ کالا) را می‌سازد:

```bash
npx tsx src/db/seed.ts
npx tsx src/db/seed-materials.ts
```

> ⚠️ `seed.ts` داده نمونه (پروژه گلشهر و...) هم می‌سازد.
> اگر فقط کاتالوگ کالاها را می‌خواهی، فقط `seed-materials.ts` را اجرا کن
> و دسته‌بندی‌ها را دستی بساز.

## قدم ۷: برنامه را اجرا کن

**برای تست (حالت توسعه):**
```bash
npm run dev
```

**برای استفاده جدی (حالت تولید):**
```bash
npm run build
npm run start
```

حالا در مرورگر باز کن: **http://localhost:3000**

## قدم ۸: نسخه دسکتاپ را به آن وصل کن

```bash
cd desktop
npm install
npm start
```

برنامه دسکتاپ باز می‌شود و به `http://localhost:3000` وصل است. ✅

برای ساخت فایل نصبی:
```bash
npm run dist:win
```

# ☁️ استقرار دائمی (برای سینک بین موبایل و کامپیوتر)

برای اینکه گوشی و کامپیوتر به یک دیتابیس وصل باشند و همیشه در دسترس باشی،
برنامه باید روی یک **سرور دائمی** با آدرس ثابت باشد.

## گزینه ۱: روی کامپیوتر/سرور خودت با Docker (یک دستور)

```bash
docker compose -f docker-compose.prod.yml up -d --build
```

تمام — برنامه روی `http://localhost:3000` بالا می‌آید، با دیتابیس خودش.

| دستور | کار |
|---|---|
| `docker compose -f docker-compose.prod.yml logs -f app` | دیدن لاگ |
| `docker compose -f docker-compose.prod.yml down` | خاموش کردن |
| `docker compose -f docker-compose.prod.yml restart app` | ری‌استارت |

> 🔒 **رمز دیتابیس را عوض کن:** یک فایل `.env` بساز و بنویس
> `POSTGRES_PASSWORD=رمز_قوی_خودت`

## گزینه ۲: Railway (ساده‌ترین، ~۵ دلار در ماه)

۱. در https://railway.app ثبت‌نام کن
۲. **New Project** ← **Deploy from GitHub repo**
۳. یک **PostgreSQL** اضافه کن (دکمه `+ New` ← `Database` ← `PostgreSQL`)
۴. متغیر `DATABASE_URL` را به متغیری که Railway می‌سازد وصل کن
۵. **Deploy** — یک آدرس ثابت مثل `daftar.up.railway.app` می‌گیری

## گزینه ۳: Render (با پلن رایگان)

۱. در https://render.com یک **Web Service** بساز
۲. ریپازیتوری را وصل کن
۳. یک **PostgreSQL** اضافه کن
۴. `DATABASE_URL` را در Environment Variables بگذار
۵. Build Command: `npm install && npm run build`
۶. Start Command: `npm run start`

## گزینه ۴: VPS ایرانی

```bash
# روی سرور
git clone <ریپازیتوری> && cd daftar-sakhteman
docker compose -f docker-compose.prod.yml up -d --build

# سپس با Nginx + SSL روی دامنه‌ات بگذار
```

## بعد از استقرار

۱. آدرس ثابت را در **موبایل** باز کن و نصبش کن (PWA)
۲. همان آدرس را در نسخه **دسکتاپ** بده: منوی برنامه ← تغییر آدرس سرور
۳. حالا هر دو به یک دیتابیس وصل‌اند = **سینک خودکار**

## ساخت جدول‌ها در سرور جدید

بار اول که روی سرور جدید مستقر می‌کنی:

```bash
docker compose -f docker-compose.prod.yml exec app npx drizzle-kit push
docker compose -f docker-compose.prod.yml exec app npx tsx src/db/seed-materials.ts
```

# 🔄 نگهداری روزمره

## روشن کردن (بعد از خاموش شدن کامپیوتر)

```bash
# ۱. دیتابیس
docker compose up -d

# ۲. برنامه (در یک پنجره ترمینال جدید)
npm run start

# ۳. نسخه دسکتاپ (پنجره سوم)
cd desktop && npm start
```

## خاموش کردن

```bash
npm run start     # با Ctrl+C متوقفش کن
docker compose stop
```

## پشتیبان‌گیری از دیتابیس ⚠️ مهم

```bash
docker compose exec db pg_dump -U postgres app_db > backup.sql
```

فایل `backup.sql` را جای امن نگه دار.

## بازگردانی پشتیبان

```bash
docker compose exec -T db psql -U postgres app_db < backup.sql
```

# ❓ مشکلات رایج

### «`docker` شناخته نمی‌شود»
Docker Desktop نصب نیست یا بعد از نصب، سیستم ری‌استارت نشده.

### «`connection refused` هنگام `drizzle-kit push`»
دیتابیس بالا نیست. اول `docker compose up -d` را بزن و صبر کن `healthy` شود.

### «پورت ۵۴۳۲ اشغال است»
PostgreSQL دیگری روی سیستم نصب داری. یا آن را متوقف کن، یا در
`docker-compose.yml` خط `"5432:5432"` را به `"5433:5432"` تغییر بده و
در `.env` هم پورت را `5433` کن.

### «آنتی‌ویروس فایل `.exe` را بلاک می‌کند»
به دلیل نداشتن امضای دیجیتال. **More info** ← **Run anyway**.

### «مک می‌گوید برنامه شناسایی نشد»
روی آیکون **کلیک راست** ← **Open** ← دوباره **Open**.

### «نسخه دسکتاپ صفحه آفلاین نشان می‌دهد»
برنامه در حال اجرا نیست. `npm run start` را بزن و بعد در منوی
**برنامه** ← **بارگذاری دوباره** (`Ctrl+R`).

# 📁 ساختار پروژه

```
├── src/
│   ├── app/            صفحات و مسیرهای API
│   ├── components/     کامپوننت‌های رابط کاربری
│   ├── lib/            منطق مالی، گزارش‌ها، پارسر پرینت بانک
│   └── db/             schema و اسکریپت‌های داده
├── desktop/            نسخه دسکتاپ (Electron)
├── public/             آیکون‌ها، manifest، service worker
├── docker-compose.yml  دیتابیس PostgreSQL
├── .env.example        الگوی فایل تنظیمات
└── drizzle.config.json تنظیمات دیتابیس
```
