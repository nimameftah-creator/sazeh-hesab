# دفتر ساختمان — نسخه دسکتاپ

این پوشه، برنامه را به یک **اپلیکیشن دسکتاپ قابل نصب** تبدیل می‌کند:

- 🪟 **ویندوز:** فایل نصبی `.exe` با راهنمای نصب گام‌به‌گام + نسخه پرتابل بدون نصب
- 🍎 **مک:** فایل `.dmg` (هم Intel هم Apple Silicon)
- 🐧 **لینوکس:** `AppImage` و `.deb`

---

## پیش‌نیاز

فقط **Node.js نسخه ۲۰ یا بالاتر** روی کامپیوترت نصب باشد.
دانلود: https://nodejs.org

برای بررسی نصب بودنش، در ترمینال (CMD / PowerShell) بنویس:

```bash
node -v
```

باید چیزی مثل `v22.11.0` نشان دهد.

---

## ساخت فایل نصبی — ۳ دستور

### قدم ۱: ورود به پوشه

```bash
cd desktop
```

### قدم ۲: نصب وابستگی‌ها (فقط یک بار)

```bash
npm install
```

> این دستور حدود ۲۰۰ مگابایت (Electron) دانلود می‌کند. یک بار انجام می‌شود.

### قدم ۳: ساخت فایل نصبی

```bash
npm run dist
```

فایل‌های نهایی در پوشه **`desktop/release/`** ساخته می‌شوند:

| فایل | توضیح |
|---|---|
| `daftar-sakhteman-1.0.0-x64.exe` | 🪟 فایل نصبی ویندوز با راهنمای گام‌به‌گام (این را نصب کن) |
| `daftar-sakhteman-1.0.0-portable.exe` | نسخه بدون نصب — فقط دابل کلیک |
| `daftar-sakhteman-1.0.0-x64.dmg` | 🍎 نصب مک Intel |
| `daftar-sakhteman-1.0.0-arm64.dmg` | 🍎 نصب مک M1/M2/M3 |

## دستورهای مخصوص هر سیستم‌عامل

اگر روی ویندوز هستی و فقط فایل ویندوز می‌خواهی:

```bash
npm run dist:win
```

روی مک:

```bash
npm run dist:mac
```

## تست سریع قبل از ساخت فایل نصبی

می‌خواهی مطمئن شوی کار می‌کند؟ بدون ساخت فایل نصبی اجرا کن:

```bash
npm start
```

پنجره برنامه باز می‌شود. اگر درست بود، `npm run dist` را بزن.

---

## تغییر آدرس سرور

آدرس برنامه در ابتدای فایل **`main.cjs`** است:

```js
const APP_URL = process.env.DAFTAR_APP_URL || "https://3000-inn9gvst6gghm3zwre52p.e2b.app";
```

اگر آدرس برنامه عوض شد، این خط را ویرایش کن و دوباره `npm run dist` بزن.

**روش بدون ویرایش فایل** (با متغیر محیطی):

```bash
# ویندوز (CMD)
set DAFTAR_APP_URL=https://آدرس-جدید.com && npm run dist

# مک / لینوکس
DAFTAR_APP_URL=https://آدرس-جدید.com npm run dist
```

## ⚠️ نکته مهم درباره اینترنت

این نسخه دسکتاپ، **پوسته‌ای (wrapper)** برای برنامه وب است. یعنی:

✅ پنجره مستقل با آیکون اختصاصی
✅ آیکون در منوی Start و دسکتاپ
✅ کلیدهای میان‌بر (بزرگ‌نمایی، بازگشت به داشبورد)
✅ فقط یک نسخه در هر لحظه باز می‌شود
✅ ذخیره اندازه و موقعیت پنجره
✅ صفحه اختصاصی هنگام قطع اینترنت

❌ اما **بدون اینترنت کار نمی‌کند** — چون داده‌ها روی سرور هستند.

اگر نسخه‌ای می‌خواهی که **کاملاً آفلاین** کار کند (دیتابیس محلی روی همین کامپیوتر، بدون سرور)،
باید برنامه به SQLite منتقل شود. این کار شدنی است ولی پروژه جداگانه‌ای است.


## مشکلات رایج

**❓ `npm install` گیر می‌کند یا خطای شبکه می‌دهد**
دانلود Electron از گیت‌هاب است. اگر فیلتر یا کُند است، یک بار VPN را روشن کن یا چند بار تلاش کن.

**❓ آنتی‌ویروس فایل نصبی را بلاک می‌کند**
چون برنامه «امضای دیجیتال» (code signing) ندارد، ویندوز SmartScreen هشدار می‌دهد.
روی **More info** و بعد **Run anyway** بزن.
برای حذف این هشدار باید گواهی کدنویسی خریداری شود.

**❓ می‌خواهم فایل نصبی را روی کامپیوتر دیگری نصب کنم**
فایل `.exe` داخل پوشه `release` را کپی کن و روی آن کامپیوتر اجرا کن.
Node.js روی آن کامپیوتر لازم نیست.

**❓ روی مک می‌گوید «برنامه شناسایی نشد»**
روی آیکون برنامه **کلیک راست** ← **Open** ← دوباره **Open**.
(چون برنامه امضا نشده است.)
